[ 01 / PROBLEM & PIVOT ]

Why Predicting Stock Prices is an Anti-Pattern

Predicting raw price points (P_t+30) creates a delayed echo of yesterday. Real financial ML forecasts stationary forward returns.

[ THE MISTAKE: RAW NOMINAL PRICE ]
P_hat(t+30) ~= P_t

Non-stationary prices trick models into outputting today's price as tomorrow's forecast with synthetic 98% R^2 and zero actual alpha.

[ THE FIX: 30-DAY FORWARD LOG RETURN ]
y_t = ln( P_{t+30} / P_t )

Enforces stationarity across all 26 Colombo Stock Exchange equities, forcing models to learn genuine momentum and cyclical turning points.

[ 03 / VALIDATION RIGOR ]

Zero Lookahead Leakage: Purged & Embargoed CV

A 30-day forward return target leaks data if standard K-Fold CV is used. We enforce a 30-day purge buffer.

[ 5-FOLD EXPANDING TIMELINE WITH EMBARGO ]
Fold 1: [== Train ==] [Purge: 30d] [Test: 60d] [Embargo: 30d]
Fold 2: [==== Train ====] [Purge: 30d] [Test: 60d] [Embargo: 30d]
Fold 3: [====== Train ======] [Purge: 30d] [Test: 60d] ...
30-DAY PURGE

Drops training samples whose 30-day horizon overlaps with test dates.

30-DAY EMBARGO

Blocks post-test auto-correlation spillover into future folds.
